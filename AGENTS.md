Here are some high level rules. The most important part of coding here is to respect INTENT.md, so you also need to load that into context.
1. Always present a plan before making changes or adding new code.
2. Avoid branching out of the stdlib packages as much as possible. Even if you have to write more code, it will be better than going external. 
3. Keep code as small as possible. Don't be overly verbose with the code, note: this doesn't mean clipping variable and function names it means keeping code as minimal as possible while still achieving the desired outcome. 
4. Keep all names descriptive enough that they make sense, but don't make them too long. 
5. Always run through the code you wrote before finishing to ensure that you have complied to these rules
